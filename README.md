# Restaurant Review Sentiment Analysis

## Description:
 A Machine Learning project that tells the review is whether positive or negative sentiments using NLP Techniques.

## Project Overview:
  - This project is about analyzes the review of the customer and predicts whether it is positive or negative sentiment.
  - Natural Language Technique(NLP) techniques are used to preprocess the text and extract the meaningful features from the customer review.
  - This project was developed as a learning project to practice Natural Language Processing, TF-IDF, machine learning classification, and Streamlit deployment.
## Objectives:
  - Analyze the customer review
  - Preprocess the text
  - Convert text data into numerical features using TF-IDF
  - Train the Machine Learning Classification models
  - predict the sentiment of new reviews
  - select the model with high accuracy 
  - Build an interactive Streamlit applicaton
## Technologies Used
  - Python
  - Pandas
  - Numpy
  - Scikit-learn
  - Natural Language Processing (NLP)
  - TF-IDF
  - Streamlit
  - Jupyter notebook

## Model
  The project uses Random Forest Classifier, Logistic Regression , Naive Bayes to classify the restaurant review
  based on the TF-IDF features extracted from the review text.

## Result
  Among all the models Logistic Regression Classification model which have the highest accuracy score of 0.8066 of model performance.
  - Accuracy: 81%
  - Precision (Class 0): 78%
  - Precision (Class 1): 84%
  - Recall (Class 0): 86%
  - Recall (Class 1): 76%
  - F1-score (Class 0): 82%
  - F1-score (Class 1): 79%
## Streamlit Application
   An interactive application was developed to allow the users to enter a restaurant review and receive a predicted sentiment.
